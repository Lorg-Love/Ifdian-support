## 使用教程

导入Release后，将"ifdian support" 与 "MainModule"打开

将MainModule右键保存至Roblox，并复制ID

进入ifdian support把第1行中require中的YOUR_MAINMODULE_ID替换为你保存的文件ID

随后将第38行中Kick内的提示语改为你自己需要的提示语

在第34行下方粘贴你主要脚本内的内容

（你还可以为这个脚本的除1-2行外进行混淆）
